Actividades y Automatizaciones

Descubrí todo lo que podés construir con Arduino, desde proyectos sencillos hasta sistemas avanzados de robótica y automatización.

¿Qué podés hacer con Arduino?

Arduino permite crear sistemas capaces de recibir información mediante sensores, procesarla mediante un programa y realizar diferentes acciones automáticamente.

💡
Automatización
Sistema de iluminación automática

Enciende y apaga una luz automáticamente utilizando un sensor de luz LDR.

¿Cómo funciona?

Luz ambiental → Sensor LDR → Arduino → LED o lámpara.

  • Arduino Uno o Nano
  • Sensor LDR
  • Resistencias
  • LED
  • Cables y protoboard

Aplicaciones: habitaciones, jardines, pasillos y ahorro energético.

Automatización
Sistema de riego automático

Controla automáticamente el riego de una planta según la humedad del suelo.

Funcionamiento

Tierra → Sensor de humedad → Arduino → Relé → Bomba.

  1. El sensor mide la humedad.
  2. Arduino recibe el valor.
  3. Compara el valor con un límite.
  4. Si la tierra está seca, activa el relé.
  5. La bomba suministra agua.

Se aprende: sensores, condicionales, automatización, relés y lectura analógica.

Robótica
Auto robot evita-obstáculos

Robot autónomo que utiliza sensores para detectar obstáculos y motores para desplazarse.

Funcionamiento

Sensor ultrasónico → Arduino → Driver de motores → Motores.

  • Más de 30 cm → avanzar
  • Menos de 30 cm → detenerse
  • Menos de 15 cm → retroceder y girar

Se puede ampliar con Bluetooth, cámara, sensores laterales, encoders y navegación.

Basurero automático

🧠 ¿Cómo funcionan estas automatizaciones?

La mayoría de los proyectos Arduino pueden entenderse mediante tres elementos principales.

📥

1. Entrada

Arduino recibe información desde diferentes sensores o dispositivos.

  • 💡 Sensor de luz
  • 🌡️ Sensor de temperatura
  • 👤 Sensor de movimiento
  • 🔘 Botón
  • 🎮 Joystick
  • 📏 Sensor de distancia
🧠

2. Procesamiento

Arduino ejecuta el programa y toma una decisión utilizando la información recibida.

SI temperatura > 30 °C
ENTONCES
encender ventilador
📤

3. Salida

Arduino realiza una acción utilizando diferentes actuadores.

  • 💡 Encender un LED
  • ⚙️ Mover un servo
  • 🔄 Activar un motor
  • 🔊 Encender un buzzer
  • 📺 Mostrar información
  • 🔌 Activar un relé apropiado

📥 ENTRADA → 🧠 PROCESAMIENTO → 📤 SALIDA
