🔌 Tipos de Arduino

Arduino tiene muchísimos modelos y cada uno está pensado para diferentes tipos de proyectos. Descubrí sus características y elegí la placa adecuada para tu proyecto.

01 · PRINCIPIANTE

Arduino Uno

El Arduino Uno es probablemente el modelo más conocido y utilizado para aprender Arduino.

ATmega328P Microcontrolador
14 Pines digitales
6 Entradas analógicas

¿Para qué sirve?

Es excelente para aprender programación, sensores, LEDs, motores, servomotores, pantallas y sistemas automáticos.

🚀 Proyecto recomendado: Sistema de riego automático.
Podés conectar un sensor de humedad del suelo y una bomba de agua para activar el riego cuando la tierra esté seca.
Dificultad: ⭐⭐☆☆☆
02 · MUCHOS COMPONENTES

Arduino Mega 2560

El Arduino Mega 2560 es mucho más grande y dispone de una cantidad considerablemente mayor de entradas y salidas que el Uno.

54 Pines digitales
16 Entradas analógicas
4 Puertos seriales

¿Para qué sirve?

Es especialmente útil cuando necesitás conectar muchos componentes al mismo tiempo: sensores, pantallas, motores, teclados, relés, servomotores y módulos de comunicación.

🚀 Proyecto recomendado: Robot con múltiples sensores.
Podés combinar sensores de distancia, sensores de línea, motores, pantalla LCD, sensores de temperatura y Bluetooth.
Dificultad: ⭐⭐⭐⭐☆

Más entradas y salidas

Ideal para proyectos grandes que necesitan controlar muchos dispositivos simultáneamente.

Pequeño pero útil

El Nano conserva la filosofía del Uno en un formato mucho más pequeño.

03 · COMPACTO

Arduino Nano

El Arduino Nano tiene prácticamente la misma filosofía del Uno, pero en un formato mucho más pequeño.

¿Para qué sirve?

  • Robots pequeños.
  • Wearables.
  • Sistemas portátiles.
  • Sensores.
  • Automatización.
  • Proyectos escolares.
🚀 Proyecto recomendado: Pulsera inteligente experimental.
Podés utilizar sensores para medir movimiento, temperatura o luz y mostrar información mediante una pequeña pantalla.
Dificultad: ⭐⭐⭐☆☆
04 · USB

Arduino Leonardo

El Arduino Leonardo utiliza el microcontrolador ATmega32U4.

Una característica muy interesante es que puede comunicarse con una computadora como si fuera un teclado o mouse USB.

¿Para qué sirve?

  • Controladores personalizados.
  • Teclados.
  • Macropads.
  • Joysticks.
  • Interfaces para videojuegos.
  • Automatización mediante botones.
🚀 Proyecto recomendado: Controlador para videojuegos.
Podés construir tu propio joystick con botones y palancas y conectarlo directamente a una computadora.
Dificultad: ⭐⭐⭐☆☆

USB personalizado

Convertí Arduino en un teclado, mouse, joystick o controlador.

⌨️
05 · MUY PEQUEÑO

Arduino Micro

El Arduino Micro comparte con Leonardo la posibilidad de funcionar como dispositivo USB y resulta interesante para proyectos compactos.

🚀 Proyecto recomendado: Teclado macro personalizado.
Podés crear una pequeña consola con botones físicos para controlar música, programas, atajos de teclado, edición de video o juegos.

Por ejemplo, un botón podría ejecutar Ctrl + C, otro Ctrl + V y otro abrir un programa.

Dificultad: ⭐⭐⭐☆☆
06 · 32 BITS

Arduino Due

El Arduino Due es bastante más potente que los modelos clásicos.

ARM Cortex-M3

Procesador de 32 bits funcionando a 84 MHz.

¿Para qué sirve?

  • Procesamiento de señales.
  • Robótica.
  • Control de motores.
  • Proyectos con muchos cálculos.
  • Sistemas electrónicos más complejos.
🚀 Proyecto recomendado: Robot autónomo avanzado.
Podés combinar sensores de distancia, motores, encoders y algoritmos de navegación.
Dificultad: ⭐⭐⭐⭐⭐
⚡

Mayor procesamiento

Pensado para proyectos que necesitan más capacidad de procesamiento.

📡

Internet de las cosas

Conectá sensores y dispositivos a Internet.

07 · IoT

Arduino MKR WiFi 1010

Este modelo está pensado especialmente para proyectos relacionados con Internet de las cosas (IoT).

Tiene conectividad Wi-Fi, lo que permite enviar información a Internet.

¿Para qué sirve?

  • Enviar datos a Internet.
  • Recibir órdenes remotamente.
  • Monitorear sensores.
  • Controlar dispositivos desde una aplicación.
  • Comunicarse con servicios en la nube.
🚀 Proyecto recomendado: Casa inteligente.
Sensores de temperatura, movimiento y luz pueden enviar información mediante Wi-Fi y permitir el control de dispositivos desde el teléfono.
Dificultad: ⭐⭐⭐⭐☆
08 · PROFESIONAL

Arduino Portenta H7

El Portenta H7 pertenece a una familia mucho más potente de Arduino y está orientado a aplicaciones profesionales y sistemas embebidos avanzados.

Tiene un procesador de arquitectura STM32H747, con dos núcleos.

¿Para qué sirve?

  • Inteligencia artificial en dispositivos.
  • Visión artificial.
  • Robótica avanzada.
  • Automatización industrial.
  • Sistemas IoT profesionales.
  • Procesamiento de datos.
  • Control de maquinaria.
🚀 Proyecto recomendado: Sistema de visión artificial.
Cámara → procesamiento → detección → acción.
El sistema detecta un objeto, determina qué es y activa un motor o mecanismo.
Dificultad: ⭐⭐⭐⭐⭐
👁️

Visión y procesamiento

Una opción para sistemas embebidos y proyectos profesionales avanzados.

🤖

Robótica conectada

Potencia y conectividad para proyectos avanzados.

09 · AVANZADO

Arduino GIGA R1 WiFi

El Arduino GIGA R1 WiFi está diseñado para proyectos que necesitan bastantes recursos y conectividad.

Combina un microcontrolador potente con Wi-Fi y Bluetooth.

¿Para qué sirve?

  • Robótica avanzada.
  • Interfaces gráficas.
  • IoT.
  • Cámaras.
  • Controladores.
  • Proyectos multimedia.
  • Automatización.
🚀 Proyecto recomendado: Robot inteligente controlado desde el celular.
Podés controlar movimiento, velocidad, luces, cámara y sensores, además de recibir información en tiempo real.
Dificultad: ⭐⭐⭐⭐⭐
10 · IoT COMPACTO

Arduino Nano 33 IoT

Es una versión moderna y pequeña orientada a proyectos IoT.

Tiene conectividad inalámbrica, permitiendo crear dispositivos conectados a Internet sin necesitar necesariamente un módulo Wi-Fi externo.

🚀 Proyecto recomendado: Estación meteorológica conectada a Internet.

🌡️ Temperatura
💧 Humedad
🌬️ Presión atmosférica
☀️ Luz

Los datos pueden enviarse a Internet.
Dificultad: ⭐⭐⭐⭐☆

Estación conectada

11 · BLUETOOTH

Arduino Nano 33 BLE

Este modelo incorpora Bluetooth Low Energy (BLE) y un microcontrolador ARM.

Es especialmente interesante para proyectos que necesitan comunicación inalámbrica y sensores.

🚀 Proyecto recomendado: Controlador inalámbrico para robots.
Podés conectar Arduino al teléfono mediante Bluetooth y controlar dirección, velocidad, luces y servomotores.
Dificultad: ⭐⭐⭐⭐☆
